# Хиромант

Клиентское веб-приложение для развлекательной интерпретации линий ладони. Фото обрабатывается локально в браузере: сервис не отправляет снимки на сервер и не требует backend.

## Локальный запуск

```bash
npm ci
npm run dev
```

Production-проверка:

```bash
npm run build
npm run preview
```

## Render Static Site

Создайте в Render сервис **Static Site**, подключите GitHub-репозиторий и укажите:

- **Build Command:** `npm ci && npm run build`
- **Publish Directory:** `dist`
- **Auto-Deploy:** `Yes` (по желанию)

Камера работает только в HTTPS-контексте. Адрес Render с HTTPS подходит; при отказе в разрешении доступна загрузка изображения.

## Важные ограничения

Автоанализ является локальной эвристической предварительной разметкой: он оценивает маску кожи, направление ладони и локальные границы изображения, после чего предлагает точки линий. Перед чтением пользователь может скорректировать их вручную.

Сервис предназначен для развлечения и саморефлексии. Хиромантия не является научным методом, диагностикой и не заменяет медицинские, психологические, юридические или финансовые рекомендации.

Загрузка ограничена изображениями до 10 МБ. Большие снимки уменьшаются перед анализом до максимального размера 1600 px по длинной стороне.
